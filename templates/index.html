Help & Features Guide

  • Data source — All records are loaded from Snowflake at startup.
  • Deferred saves — Edits to any field are held in memory until explicitly saved. The Save Changes badge shows how many records have unsaved changes.
  • Save Changes — Writes all pending changes to Snowflake in a single batch operation.
  • Approve Selected auto-saves — Bulk-approving selected rows saves to Snowflake immediately — no separate Save step needed.
  • Refresh () — Reloads all data from Snowflake. Any unsaved changes will be discarded.
  • Import Source IDs — Choose JIB, Rev, or Vendor from the BA type dropdown, then upload a CSV/TXT file of Source IDs (one per line) to bulk-set that flag across matching records.

  • Recommendation filter — Multi-select dropdown. Check one or more recommendation types to show only those rows. No boxes checked = show all.
  • Recommendation cards — Click any card in the summary bar to jump straight to that recommendation type. Click again or use Clear to reset.
  • SSN Match — Filter to Yes (score = 100) or No (score = 0).
  • Min / Max Name Score — Show only rows where the Name Score falls within the selected range.
  • Min / Max Addr Score — Show only rows where the Address Score falls within the selected range.
  • Search box — Type to instantly filter across all visible text columns (case-insensitive).
  • Clear — Resets all active filters and clears row selections in one click.

  • Opening — Click Search & Replace in the toolbar. The modal can be dragged by its header bar to move it out of the way.
  • Scope — Search & Replace only operates on rows currently visible in the grid (after all filters are applied). Hidden rows are never affected.
  • Highlights — Matching text is highlighted yellow across all visible matching cells as you type. The current focused match is shown in red.
  • Column — Limit the search to a specific column, or leave it on All Columns to search across all editable text fields.
  • Case sensitive — Toggle the checkbox to make the search case-sensitive.
  • Find Next — Scrolls to and highlights the next match in the grid.
  • Replace — Replaces the current match only and advances to the next one.
  • Replace All — Replaces every match in all visible rows at once. Changes are held as pending until Save Changes is clicked.

  • Column sorting — Click any column header to sort ascending / descending.
  • Column reordering — Drag column headers left or right to rearrange the layout. The checkbox column is pinned to the left.
  • Column resizing — Drag the right edge of any column header to adjust its width.
  • Show / Hide Columns — Use the column visibility dropdown to toggle any column on or off. Columns are colour-coded by type: Source DEC General
  • Hidden by default — Run ID, Address Lookup, Source ID, DEC Code, JIB, Rev, Vendor, and Actions columns are hidden on load. Reveal them via Show / Hide Columns.
  • Row count — The grid info bar shows how many rows are currently displayed vs the total loaded.

  • Row checkboxes — Check individual rows to select them. Selection persists when filters change or the grid scrolls.
  • Select All — The header checkbox selects or deselects all currently visible rows.
  • Cell click — Click any cell to highlight it in blue and prepare its value for copying.
  • Shift+click (same column) — Extends the selection to a range of cells within the same column.
  • Shift+click (different column) — Selects the entire row of the clicked cell.
  • Ctrl+C — Copies all highlighted cell values to the clipboard, one value per line.
  • Download Selected () — Exports all checkbox-selected rows to a CSV file.

  • Edit button () — Opens a side-by-side modal comparing Source (editable: name, address, city, state, zip) against DEC (read-only) fields, with match scores and a Recommendation dropdown.
  • Quick Approve () — Sets a single record's recommendation to APPROVED in one click without opening the edit modal. Queued as a pending change.
  • Approve Selected — Bulk-sets all checkbox-selected rows to APPROVED and saves to Snowflake immediately, including each row's current Process value.
  • Process column — Click any Process cell to select a value: Add new BA and address, Add address to existing BA, Merge BA and address, or Manual Review - DNP. Values are pre-filled automatically from the recommendation type and saved when you approve.
  • Memo column — Click any Memo cell to type a free-text note. Confirms on Enter or click-away; cancels on Escape. Also editable in the Edit modal.
  • Address Reason column — Free-text field for recording the reason behind an address decision. Editable inline.
  • JIB / Rev / Vendor — Toggle BA type flags directly in the grid. If multiple cells in the same column are selected, toggling one applies to all selected rows.
  • Undo / Redo — The and buttons (or Ctrl+Z / Ctrl+Y) step through the change history, including bulk approvals.

  • Eligibility — A record is eligible to stage when its recommendation is APPROVED and it has a Process value set.
  • Stage Approved — The Stage Approved button (enabled when eligible records exist) moves all eligible records to the staging table in Snowflake. Their recommendation changes to STAGED and they are hidden from the default grid view.
  • Save first — Any unsaved changes must be saved before staging. The button is blocked if pending changes exist.
  • Badge count — The number next to Stage Approved shows how many records are currently eligible.

  • Orange rows — Source name or address contains a trust/estate keyword ("trust", "trst", "estate", etc.).
  • Red cells — Cell value contains a "Do Not Use" variation (DO NOT USE, DON'T USE, DNU, etc.).
  • Score badges — 100 perfect  90+ high  75+ medium  <75 low.
  • SSN badges — Yes = score 100 (full match)  No = score 0 (no match).
  • Name score tooltip — Hover over a Name Score below 45 for a note that the low score may result from the name appearing in the address field rather than the name field.
  • Recommendation badges — NEW BA AND NEW ADDRESS   EXISTING BA ADD NEW ADDRESS   EXISTING BA AND EXISTING ADDRESS   NEEDS REVIEW   PROCESSED   STAGED
  • Cell selection — Blue highlight on clicked or range-selected cells.
  • Search highlights — While Search & Replace is open, all matching cells show yellow on the matched text; the current match is red.
